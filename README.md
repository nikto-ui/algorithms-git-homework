# Git: задачи, ветки и коммиты

## Какие задачи решает Git

Git — распределённая система контроля версий. Она сохраняет историю изменений файлов проекта и помогает вернуться к прежнему состоянию, сравнить версии и понять, кто и когда внёс изменения.

Git позволяет нескольким участникам работать над одним проектом: каждый может вести изменения отдельно, а затем объединить их. Если изменения в одних и тех же строках несовместимы, Git сообщает о конфликте, который нужно разрешить вручную. Репозиторий можно хранить локально и синхронизировать с удалённым сервером, например GitHub.

Git — это инструмент контроля версий, а GitHub — сервис для размещения репозиториев и совместной работы с ними.

## Что такое коммит

**Коммит** — сохранённый снимок отслеживаемого состояния проекта. У него есть уникальный идентификатор, автор, дата и сообщение, описывающее изменения. Коммиты образуют историю: обычно каждый коммит ссылается на предыдущий, а коммит слияния может иметь несколько родителей.

Чтобы создать коммит, сначала выбирают изменения командой `git add`, затем сохраняют их командой `git commit`:

```bash
git add README.md
git commit -m "Добавить ответы на вопросы о Git"
```

## Что такое ветка

**Ветка** — подвижная ссылка на коммит. Обычно основная ветка называется `main`; отдельную ветку можно создать для новой задачи или исправления. Новые коммиты передвигают текущую ветку вперёд, не меняя другие ветки. Готовые изменения можно объединить с основной веткой с помощью слияния (`merge`).

Например:

```bash
git switch -c feature/readme  # создать ветку и перейти в неё
# изменить файл, добавить его и создать коммит
git switch main               # вернуться в основную ветку
git merge feature/readme      # объединить изменения
```

Локальный репозиторий можно связать с удалённым и отправить туда коммиты:

```bash
git remote add origin https://github.com/ИМЯ_ПОЛЬЗОВАТЕЛЯ/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```
# Корутины
## Корутины (Coroutines)

1. Что такое корутины?

Корутины (Coroutines) — это механизм программирования, который позволяет выполнять задачи асинхронно, приостанавливать их выполнение и продолжать позже с того же места.

Они помогают выполнять несколько задач, не блокируя основной поток программы.

Корутины широко используются для работы с интернет-запросами, базами данных, файлами и другими операциями, которые требуют ожидания.

2. Как работают корутины?

Основные этапы работы:

1. Создание корутины.
2. Запуск выполнения.
3. Приостановка выполнения при необходимости.
4. Выполнение других задач.
5. Возобновление корутины.
6. Завершение выполнения.

Главная особенность корутин — возможность приостанавливать выполнение без блокировки потока.

3. Основные ключевые слова Python

* async — объявляет асинхронную функцию.
* await — ожидает завершения асинхронной операции.
* asyncio — библиотека для работы с корутинами.
* asyncio.run() — запускает асинхронную функцию.
* asyncio.sleep() — приостанавливает корутину на определённое время.
* asyncio.gather() — позволяет запускать несколько асинхронных задач и ожидать их завершения.
* asyncio.create_task() — создаёт отдельную асинхронную задачу.

4. Примеры использования корутин

Пример 1. Простая корутина

```import asyncio
async def hello():
    print("Привет!")
    await asyncio.sleep(1)
    print("Корутина завершена")
asyncio.run(hello())
```
## Объяснение:

* async def создаёт асинхронную функцию.
* await asyncio.sleep(1) приостанавливает выполнение на одну секунду.
* asyncio.run() запускает корутину.

Пример 2. Несколько корутин

```import asyncio
async def task1():
    print("Задача 1 началась")
    await asyncio.sleep(2)
    print("Задача 1 завершена")
async def task2():
    print("Задача 2 началась")
    await asyncio.sleep(1)
    print("Задача 2 завершена")
async def main():
    await task1()
    await task2()
asyncio.run(main())
```
Объяснение:

В этом примере две корутины выполняются последовательно. Сначала завершается первая задача, затем начинается вторая.

Пример 3. Параллельное выполнение корутин

```import asyncio
async def task(name, seconds):
    print(f"{name}: начало")
    await asyncio.sleep(seconds)
    print(f"{name}: завершение")
async def main():
    await asyncio.gather(
        task("Задача 1", 3),
        task("Задача 2", 2),
        task("Задача 3", 1)
    )
asyncio.run(main())
```

## Объяснение:

Функция asyncio.gather() позволяет выполнять несколько корутин одновременно в рамках одного цикла событий.

Все задачи запускаются вместе, поэтому общее время ожидания составляет примерно 3 секунды, а не 6.

5. Преимущества корутин

1. Экономия ресурсов.
2. Удобная работа с асинхронными операциями.
3. Возможность выполнять множество задач.
4. Улучшение отзывчивости приложений.
5. Упрощение асинхронного программирования.
6. Возможность приостанавливать выполнение без блокировки потока.

6. Недостатки корутин

1. Требуют понимания асинхронного программирования.
2. Отладка может быть сложнее.
3. Не все операции можно эффективно выполнять асинхронно.
4. Неправильное управление задачами может привести к ошибкам.

7. Отличие корутин от потоков

Потоки (Threads) — единицы выполнения, которыми управляет операционная система.

Корутины (Coroutines) — лёгкие задачи, которые могут приостанавливать и возобновлять своё выполнение.

## Основные отличия:

Потоки	Корутины
Управляются ОС	Управляются средой выполнения
Требуют больше ресурсов	Обычно более лёгкие
Могут выполняться параллельно	Часто переключаются в одном потоке
Используются для параллельных задач	Удобны для асинхронных задач

8. Где используются корутины?

* Разработка мобильных приложений.
* Серверная разработка.
* Работа с базами данных.
* Загрузка данных из интернета.
* Обработка большого количества запросов.
* Асинхронная работа с файлами.

9. Заключение
Корутины являются важной частью современного программирования. Они позволяют эффективно управлять асинхронными задачами, экономить ресурсы и создавать отзывчивые приложения.
Благодаря корутинам разработчики могут писать более понятный и удобный асинхронный код.
Они особенно полезны в программах, где необходимо одновременно ожидать выполнения большого количества операций.
